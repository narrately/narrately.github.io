Local-first isn't a setting. It's the shape.

Every claim here is backed by code in the repository — not a policy page.

Nothing leaves the machineunless you enable email, an LLM narrative, or a team.
Metadata only, by defaultpaths, timestamps, commit subjects, counts — never contents.
No command output, everthe shell hook logs the command, not what it printed.
Exclusions before storageexcluded paths and patterns never reach the database.
Loopback-only daemonbound to 127.0.0.1, never reachable off the machine.
Code capture is opt-inthree independent layers, secrets redacted before disk.

Read the privacy model in the docs, or the collectors themselves in the source.
