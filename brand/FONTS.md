# Bundled fonts

The web surfaces self-host these faces (latin subsets, WOFF2) in `website/assets`,
`src/web/assets`, and `cloud/dashboard/assets`, so nothing is fetched from a font CDN.

| Face | Files | Designer | License |
|---|---|---|---|
| Barlow | `barlow-400/500/600.woff2` | Jeremy Tribby | SIL Open Font License 1.1 |
| Barlow Semi Condensed | `barlow-sc-500/600/700.woff2` | Jeremy Tribby | SIL Open Font License 1.1 |
| Overpass Mono | `overpass-mono.woff2` (variable) | Delve Withrington for Red Hat | SIL Open Font License 1.1 |
