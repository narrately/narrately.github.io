# Team portal (cloud/dashboard/index.html)

Mode: Operate (auth screens are a light Persuade moment inside it). Inherits the chart-recorder world at Operate register, the same component language as the local dashboard. Task: sign in, create or join a team, read the team's week by member and project, manage members and invites, export a CSV timesheet, see trial/billing status and upgrade (owner). Every element ID, the supabase-js flow and config.js loading are preserved. Synthetic numbers never appear here; this portal only shows real data.
